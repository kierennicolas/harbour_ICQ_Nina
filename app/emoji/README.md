# Emoji images

These PNGs are from [Twemoji](https://github.com/jdecked/twemoji) (the
community-maintained continuation of Twitter's emoji set), 72x72, a curated
subset used by the emoji picker and to show emoji in messages.

Graphics copyright 2020 Twitter, Inc and other contributors, and the
jdecked/twemoji contributors; licensed under CC-BY 4.0
(`LICENSE-GRAPHICS`, <https://creativecommons.org/licenses/by/4.0/>).

`emoji.json` lists the picker's categories: `t` is the text inserted, `f` the
image file name (code points in hex, without U+FE0F).
